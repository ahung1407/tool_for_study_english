# Hướng Dẫn Cài Đặt Gemini Edge Extension

Extension này cho phép bạn bôi đen văn bản trên web và nhờ Gemini AI giải thích hoặc dịch.

## 1. Chuẩn bị

- Đảm bảo bạn đã có **Gemini API Key**. Nếu chưa, lấy tại: [https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)

## 2. Cài đặt vào Microsoft Edge

1.  Mở trình duyệt Edge.
2.  Nhập vào thanh địa chỉ: `edge://extensions/` và nhấn Enter.
3.  Bật **Developer mode** (Chế độ nhà phát triển) ở thanh menu bên trái hoặc góc dưới.
4.  Nhấn nút **Load unpacked** (Tải bản giải nén).
5.  Trỏ đến thư mục `d:\Minh_Hung\Documents\học tập\doc\tools\Gemini_Edge_Extension` và nhấn **Select Folder**.

## 3. Cấu hình

1.  Sau khi cài xong, icon tiện ích (Gemini AI Helper) sẽ hiện trên thanh công cụ của Edge (có thể nằm trong menu mảnh ghép 🧩).
2.  Click vào icon đó.
3.  Dán **Gemini API Key** của bạn vào ô trống và nhấn **Lưu Cấu Hình**.

## 4. Sử dụng

1.  Mở một trang web bất kỳ (ví dụ: một bài báo tiếng Anh).
2.  **Lưu ý:** Nếu trang web đã mở trước khi cài extension, hãy F5 (tải lại) trang đó.
3.  Bôi đen một đoạn văn bản.
4.  Một icon nhỏ hình ngôi sao/lấp lánh (✨) sẽ hiện ra ngay cạnh.
5.  Click vào icon đó và đợi kết quả từ Gemini!
